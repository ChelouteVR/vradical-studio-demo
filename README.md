# VRadical Studio demos

Download the **universal VRadical Studio demo** for macOS and Windows.

[**Download the latest universal demo**](https://github.com/ChelouteVR/vradical-studio-demo/releases/latest)

| Platform | Requirements | Download |
| --- | --- | --- |
| macOS | Apple Silicon, macOS 26.0 or later | `.dmg` installer |
| Windows | x64 PC with a compatible hardware Direct3D 11 GPU | `Setup.exe` installer |

The universal demo includes every registered camera pipeline and accepts supported recordings from any camera serial. It includes preview, mixed-camera timeline editing, automatic calibration, audio processing, color grading, image correction and DeoVR Classic headset streaming.

Stabilization is available except for Canon and CALF. Photo processing is available for supported cameras except DJI Osmo I/II and GoPro MAX2.

File export, interpolation and publishing require the full version. Export settings remain available in the demo.

## Install

- **macOS:** open the DMG and drag the application to Applications.
- **Windows:** run the setup executable and follow the installer.

The macOS application and DMG are Developer ID signed, Apple notarized and stapled, with Gatekeeper validation. The Windows installer is unsigned.

Each release includes `SHA256SUMS.txt` to verify the downloads, its source revision and validation details.

## Legacy demos

The earlier [Insta360 EVO demo](https://github.com/ChelouteVR/vradical-studio-demo/releases/tag/v1.0.0-insta360-evo-demo.2) remains available. Its camera and feature restrictions differ from the universal demo; see that release's notes.

## About this repository

This repository hosts download information and packaged demos. Studio source code is not included.
